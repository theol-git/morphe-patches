# Personal Morphe patches

Personal [Morphe](https://morphe.software) patches.

## Patches

- **Pro unlock** (`app.prolauncher`, Pro Launcher v2.4.3): forces the trial-window check
  `x9.v0.h()` to `true`, which makes `v0.t()` and the subscriber pro gate true, and suppresses
  the trial sheet in `ComposeMainActivity.onResume`.

## Add to Morphe Manager

Add the source from GitHub: `morphe.software/add-source?github=theol-git/morphe-patches`
(replace the placeholder with your GitHub user, after the repo is pushed and has a release).

## Development

- Make changes on the `dev` branch.
- Build locally with `./gradlew buildAndroid`. The `.mpp` file is written to `patches/build/libs/`.
- Use semantic commit messages (`feat:`, `fix:`, `chore:`).
- `patches-list.json`, `patches-bundle.json` and `CHANGELOG.md` are generated by the release workflow. Do not edit them by hand.
